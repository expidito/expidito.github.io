# Kadr website rules

- Use only plain HTML and CSS. No JavaScript, frameworks, dependencies, or build step.
- Do not add analytics, cookies, external fonts, embeds, or assets loaded from third-party servers. Use system fonts and local assets only. Ordinary outbound links are allowed.
- SITE-BRIEF.md is the only source of product facts and copy. Do not invent features, claims, prices, contacts, dates, or links. Ask the owner for missing information.
- Clearly distinguish planned purchases and subscription behavior from features already implemented. Kadr is not yet released in the Mac App Store.
- Never commit SITE-BRIEF.md or Kadr application source code to this public website repository.
- Work on main. At the end of each change, show git diff --stat and make a commit. Push when requested.
- Keep the website in English until other languages are requested.
- Maintain permanent page URLs: /, /support/, /privacy/, and /terms/.
- Use relative links with explicit index.html filenames so every page also works when index.html is opened directly from Finder.
- Preserve responsive layouts, system light/dark appearance, accessible navigation, and visible keyboard focus.
- Add the app icon, screenshots, and App Store button only when requested and supplied. Do not mock up the application interface.
