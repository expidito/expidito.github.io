# Kadr website

English website for Kadr, a macOS screenshot and screen recording app.

Plain HTML and CSS, with no build step or external resources. Open `index.html`
from Finder, or serve this directory with any static HTTP server.

Published from `main` on GitHub Pages:

- Home: https://expidito.github.io/
- Support: https://expidito.github.io/support/
- Privacy Policy: https://expidito.github.io/privacy/
- Terms of Use: https://expidito.github.io/terms/

Links explicitly include `index.html` to work on both GitHub Pages and `file://`.
The directory URLs above remain the permanent public addresses.
